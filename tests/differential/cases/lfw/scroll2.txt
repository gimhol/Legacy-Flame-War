# 4BO：ScrollView 默认 thumb id（scroll_thumb）兜底 —— 独立树

# ---- 0) 场景：两个无 scrollbar_thumb 属性的 ScrollView 共用全局 id 为 scroll_thumb 的节点 ----
nmk crt - o 5 id s "crt" pos a 3 n 0 n 0 n 0 size a 3 n 400 n 300 n 1 center a 3 n 0 n 0 n 0 scale a 3 n 1 n 1 n 1
nmk st1 crt o 6 id s "st1" pos a 3 n 20 n 20 n 0 size a 3 n 200 n 100 n 1 center a 3 n 0 n 0 n 0 scale a 3 n 1 n 1 n 1 component a 1 o 4 cls s "ScrollView" id s "sst1" args a 0 properties o 2 content s "id:ct1" speed n 1
nmk ct1 st1 o 5 id s "ct1" pos a 3 n 0 n 0 n 0 size a 3 n 200 n 100 n 1 center a 3 n 0 n 0 n 0 scale a 3 n 1 n 1 n 1
nmk u1 ct1 o 5 id s "u1" pos a 3 n 0 n 0 n 0 size a 3 n 200 n 100 n 1 center a 3 n 0 n 0 n 0 scale a 3 n 1 n 1 n 1
nmk u2 ct1 o 5 id s "u2" pos a 3 n 0 n 100 n 0 size a 3 n 200 n 100 n 1 center a 3 n 0 n 0 n 0 scale a 3 n 1 n 1 n 1
nmk u3 ct1 o 5 id s "u3" pos a 3 n 0 n 200 n 0 size a 3 n 200 n 100 n 1 center a 3 n 0 n 0 n 0 scale a 3 n 1 n 1 n 1
nmk tk crt o 5 id s "tk" pos a 3 n 240 n 20 n 0 size a 3 n 10 n 100 n 1 center a 3 n 0 n 0 n 0 scale a 3 n 1 n 1 n 1
nmk scroll_thumb tk o 5 id s "scroll_thumb" pos a 3 n 0 n 0 n 0 size a 3 n 10 n 10 n 1 center a 3 n 0 n 0 n 0 scale a 3 n 1 n 1 n 1
nmk st2 crt o 6 id s "st2" pos a 3 n 20 n 160 n 0 size a 3 n 200 n 100 n 1 center a 3 n 0 n 0 n 0 scale a 3 n 1 n 1 n 1 component a 1 o 4 cls s "ScrollView" id s "sst2" args a 0 properties o 2 content s "id:ct2" speed n 1
nmk ct2 st2 o 5 id s "ct2" pos a 3 n 0 n 0 n 0 size a 3 n 200 n 100 n 1 center a 3 n 0 n 0 n 0 scale a 3 n 1 n 1 n 1
nmk v1 ct2 o 5 id s "v1" pos a 3 n 0 n 0 n 0 size a 3 n 200 n 100 n 1 center a 3 n 0 n 0 n 0 scale a 3 n 1 n 1 n 1
nmk v2 ct2 o 5 id s "v2" pos a 3 n 0 n 100 n 0 size a 3 n 200 n 100 n 1 center a 3 n 0 n 0 n 0 scale a 3 n 1 n 1 n 1
nmk v3 ct2 o 5 id s "v3" pos a 3 n 0 n 200 n 0 size a 3 n 200 n 100 n 1 center a 3 n 0 n 0 n 0 scale a 3 n 1 n 1 n 1
nadd crt st1
nadd st1 ct1
nadd ct1 u1
nadd ct1 u2
nadd ct1 u3
nadd crt tk
nadd tk scroll_thumb
nadd crt st2
nadd st2 ct2
nadd ct2 v1
nadd ct2 v2
nadd ct2 v3

# ---- 1) st1：默认 id 兜底命中（含缓存）----
nlife st1 start
nset st1 update 16
svd st1
svsb st1
nrd scroll_thumb size
svto st1 200
nset st1 update 16
svd st1
nrd scroll_thumb pos
svsb st1

# ---- 2) st2：第二个实例各自缓存同一 thumb（驱动尺寸/位置）----
nlife st2 start
nset st2 update 16
svd st2
svsb st2
nrd scroll_thumb size
svto st2 100
nset st2 update 16
svd st2
nrd scroll_thumb pos
svsb st2
svto st1 0
nset st1 update 16
nrd scroll_thumb pos
