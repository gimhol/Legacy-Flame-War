# `loader/get_val_from_collision`：86 条碰撞求值表（顺序同 `defines/CollisionVal.ts`）。
# 每行 `run cv s "<word>"` 都是 `get_val_getter_from_collision(word)` 查表再调用：
# `has=1` 时印 getter 的返回值，`has=0` 是 TS 的 `undefined`（表里没有就不能调用）。
#
# TS 的 `Collision.attacker` / `.victim` 是那两个**活**实体（读的时候才取字段），端口的
# `Collision` 只有 `CollisionActor` 快照 ⇒ `run cvwho` 只写 `id`，实体由宿主装的
# `CollisionValEnv`（`world.entity_map.get(id) ?? null`）按 `id` 交回来；`none` = 世界外的
# id。`itr` / `bdy` / `aframe` / `bframe` 在两边都一律是对象（读不到的字段才是 `undefined`），
# 所以「世界外」那几行只能探 TS 那边也读得下去的词（见 DESIGN §63 的差异表）。
