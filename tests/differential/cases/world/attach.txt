# 4BW：`EntityCollisionView` / `EntityStateView` 的帧几何三缝与 `attach` 转发
# （`Buff::place_effect_center` 的 `{ centery = 0, height = 0, pic }` / `pic?.h ?? 0`
# 与 `Buff::show_effect` 的 `effect.attach(true)` 读的就是这两组缝）。
#
# `wgeom <label>`：经 `EntityCollisionView` 回显 `frame_centery / frame_height /
# frame_pic_h`（TS 侧按同一读法直接读 `e.frame`）。
# `wattach <label> <1|0>`：经视图转 `Entity::attach`；回显 `mounted` 与世界实体数。
#
# 帧几何的观察策略：三字段值互不相同（25 / 60 / 42）⇒ 「取错字段」可分；
# 再各来一份「缺字段」的帧 ⇒ 「缺省 0」可分；一份「无 pic」⇒ `pic?.h ?? 0` 的链可分。
wnew
wplayer 7

# -- 1. 进帧后 centery / height / pic.h 三字段齐（值互不相同）--
#     `attach` 会跑 `enter_frame(Defines.NEXT_FRAME_AUTO)`（帧 id 为 None 时）⇒ 帧变成数据里的 "0"。
wmk GA o 4 id s "GA" type n 8 base o 2 name s "GAB" resting_max n 5 frames o 1 0 o 7 id s "0" centerx n 0 centery n 25 height n 60 state n 1 wait n 30 pic o 5 tex s "" x n 0 y n 0 w n 10 h n 42
wattach GA 1
wgeom GA

# -- 2. 缺 centery / height（只剩 pic.h）⇒ 两个缺省 0 --
wmk GB o 4 id s "GB" type n 8 base o 2 name s "GBB" resting_max n 5 frames o 1 0 o 5 id s "0" centerx n 0 state n 1 wait n 30 pic o 5 tex s "" x n 0 y n 0 w n 10 h n 42
wattach GB 1
wgeom GB

# -- 3. 无 pic（三个量都会走缺省链，pic?.h ?? 0 落到 0）--
wmk GC o 4 id s "GC" type n 8 base o 2 name s "GCB" resting_max n 5 frames o 1 0 o 4 id s "0" centerx n 0 state n 1 wait n 30
wattach GC 1
wgeom GC

# -- 4. attach 转发：未挂实体（mounted 0）经视图 attach(true) ⇒ mounted=1、入列、ghosted=1、离地 --
wmk HA o 4 id s "HA" type n 8 base o 2 name s "HAB" resting_max n 5 frames o 1 0 o 5 id s "0" centerx n 0 centery n 0 state n 1 wait n 30
went HA pos n 100 n 200 n 0
wattach HA 1
wentump HA
# 重复 attach 被 `_mounted` 门挡（入列数不变、ghosted 保真）
wattach HA 1
wattach HA 0
wentump HA

# -- 5. 地面上的实体：attach(false) 走非幽灵支（进 entities）且 `is_on_ground` 为真 --
wmk HB o 4 id s "HB" type n 8 base o 2 name s "HBB" resting_max n 5 frames o 1 0 o 5 id s "0" centerx n 0 centery n 0 state n 1 wait n 30
went HB pos n 300 n 0 n 0
wattach HB 0
wentump HB
