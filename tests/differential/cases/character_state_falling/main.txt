# character_state_falling
# `env state|dataid|frameid|onlanding|idxbounce|idxfalling|idxcritical|idxlying|shaking|wait|hp|facing|vx|vz|bounced|fuse|fall|fallmax|defend|defmax|rest|restmax|finj|tinj|pos|dvals|vel`
# take value literals; `env vy <bare number>`; `env catcher <truthy>`.
# run make|default|enter|update|landing|leave
# StateEnum.Falling=12; dvals keys: cha_bc_tst_spd_y / cha_bc_tst_spd_x / cha_bc_spd
# The frame ids inside `idxbounce` / `idxfalling` / `idxcritical` / `idxlying` must be
# strings: `enter_frame_by_id(undefined)` renders "undefined" on the C++ side while TS
# logs `u`.

env state n 12
env pos o 3 x n 1 y n 2 z n 3
env dataid s "A"
env frameid s "F1"
env onlanding u
env idxbounce o 2 -1 a 2 s "L1" s "B1" 1 a 2 s "R1" s "B2"
env idxfalling o 2 -1 a 4 s "FD0" s "FD1" s "FD2" s "B2" 1 a 4 s "FU0" s "FU1" s "FU2" s "C1"
env idxcritical o 2 -1 s "C1" 1 s "C2"
env idxlying o 2 -1 s "LY1" 1 s "LY2"
env shaking n 0
env wait n 0
env hp n 5
env facing n 1
env vx n 0

env vel o 3 x n 0 y n 0 z n 0
run make
