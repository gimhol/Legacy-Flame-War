# Legacy Flame War

2D 横版格斗游戏，C++ 实现。

## 构建

```bash
npm run native configure
npm run native build
```

## 运行

```bash
npm run godot
```

## 打包

```bash
npm run godot:pack        # -> release/Legacy Flame War_godot_<版本>/
npm run godot:pack:zip    # 同上，外加同名 .zip
```
